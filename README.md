# 🤖 Freelance Exchange Bot (MVP)

Телеграм-бот для организации биржи фриланс-услуг.

### 🌟 Основные функции:
- **Двухсторонняя система**: Переключение между ролями Заказчика и Фрилансера.
- **Безопасные сделки**: Заморозка (Hold) средств при создании заказа.
- **Финансовый движок**: Полная история транзакций (ACID) в SQLite.
- **Машина состояний**: Умный процесс создания заказа через FSM.

### 🛠 Стек технологий:
- Python 3.11
- Aiogram 3.x (Асинхронный фреймворк)
- Aiosqlite (Асинхронная БД)
