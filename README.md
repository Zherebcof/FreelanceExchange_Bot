# 🤖 Freelance Exchange Bot (MVP)

Телеграм-бот для организации полноценной биржи фриланс-услуг с системой безопасных сделок.

## 🌟 Основные функции

* **Двухсторонняя система**: Мгновенное переключение между ролями Заказчика и Фрилансера в одном интерфейсе.
* **Безопасные сделки (Escrow)**: Автоматическая заморозка (Hold) средств на балансе заказчика при создании заказа.
* **Финансовый движок**: Строгая логика транзакций (ACID) на базе SQLite для исключения ошибок при расчетах.
* **Машина состояний (FSM)**: Пошаговый и интуитивно понятный процесс создания заказов и подачи откликов.

## 🛠 Стек технологий

* **Язык**: Python 3.11+
* **Библиотека**: Aiogram 3.x (Асинхронный подход)
* **База данных**: Aiosqlite (Асинхронная работа с данными)
* **Контейнеризация**: Docker & Docker Compose (Гарантия запуска на любом сервере)
* **Окружение**: Python-dotenv (Безопасное хранение ключей)
